# UniTrack

Sistema de busca e gerenciamento de alunos de diferentes polos da
Universidade Cruzeiro do Sul.

## Tecnologias

- Java
- SpringBoot
- JavaFX
- Estrutura de Dados
- Árvore de Busca

## Objetivo

Desenvolver um sistema capaz de cadastrar e localizar alunos,
organizados de acordo com seus respectivos polos.
